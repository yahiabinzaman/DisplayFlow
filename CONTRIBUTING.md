# Contributing to DisplayFlow

Thank you for your interest in improving **DisplayFlow**! Contributions, feature requests, and bug reports are warmly welcomed.

## How to Contribute
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/DisplayFlow.git
   ```
3. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make your changes** and test using `./build_app.sh`.
5. **Commit your changes**:
   ```bash
   git commit -m "Add amazing feature"
   ```
6. **Push to your branch**:
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request** on GitHub!

---

## Code Style
- Written natively in **Swift 6 / SwiftUI**.
- Follow Apple's Human Interface Guidelines (HIG) for macOS.
